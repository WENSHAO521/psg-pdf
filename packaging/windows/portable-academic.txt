PSG Academic PDF portable mode

While this file sits next to psg-academic-pdf.exe, PSG Academic PDF keeps its window settings and
its projects folder in the PSGAcademicPDFData folder beside it, and writes nothing to %APPDATA%.
Copy the whole folder to move PSG Academic PDF with its projects.

Delete this file to use the normal per-user folder (%APPDATA%\PSG Academic PDF) instead. If
PSGAcademicPDFData can't be written (for example on a read-only drive), PSG Academic PDF uses the
per-user folder and says so in its Activity log.

PSG Academic PDF typesets with the TeX installation on this computer (pdflatex, latexmk and biber;
pandoc for Word manuscripts). The portable copy doesn't carry TeX.

The journal templates are in templates\academic beside the exe. The PSG Research Article
template is also built in.
